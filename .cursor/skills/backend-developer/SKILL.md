Эксперт по backend-разработке (Symfony, PHP). Используйте этот навык при написании и рефакторинге кода на стороне сервера.

## Правила безопасности и обработки ошибок в контроллерах

- **Никогда** не выводите текст исключений напрямую в ответах API.
- Конструкции вида `return $this->json(['error' => $e->getMessage()]);` строго запрещены. Сырые сообщения об ошибках могут содержать чувствительные данные о системе, такие как пути к файлам, SQL-запросы, учетные данные или внутреннюю логику.
- Вместо этого возвращайте заранее определенные, безопасные и понятные пользователю сообщения (например, `'error' => 'Quest not found'`, `'error' => 'Invalid request format'`).
- Если необходимо передать специфичную информацию из доменного исключения, извлекайте только безопасные данные (например, ID), но не используйте `$e->getMessage()` целиком.
