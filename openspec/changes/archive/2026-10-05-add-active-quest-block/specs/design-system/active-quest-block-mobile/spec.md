## Purpose

Предоставляет переиспользуемый UI-компонент для отображения краткой информации об активном квесте пользователя в мобильном приложении.

## ADDED Requirements

### Requirement: Отображение карточки активного квеста
Компонент `ActiveQuestBlock` ДОЛЖЕН отображать название квеста, текущий прогресс (номер текущего шага и общее количество шагов) и кнопку/индикатор для перехода к экрану прохождения.

#### Scenario: Успешное отображение компонента
- **WHEN** компонент получает данные о прогрессе квеста со статусом `in_progress`
- **THEN** он корректно рендерит название квеста, прогресс (например, "Шаг 2 из 5") и кнопку "Продолжить"
- **AND** при нажатии на компонент или кнопку происходит навигация на экран прохождения этого квеста
- **TESTS**:
  - UI Check: `mobile/lib/app/core/design_system/widgets/active_quest_block.dart` корректно отрисовывает карточку с нужными данными.

#### Scenario: Отсутствие активного квеста
- **WHEN** компонент не получает данных о прогрессе или статус не равен `in_progress`
- **THEN** компонент ничего не рендерит (возвращает пустой виджет или `SizedBox.shrink()`)
- **TESTS**:
  - Code Review: `mobile/lib/app/core/design_system/widgets/active_quest_block.dart` возвращает `SizedBox.shrink()` если данные пусты.
