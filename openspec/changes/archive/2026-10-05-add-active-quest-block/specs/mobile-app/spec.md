## MODIFIED Requirements

### Requirement: R03 — Каталог квестов и геопоиск
Приложение ДОЛЖНО предоставлять список квестов с фильтрами (город, сложность, популярные), детальной карточкой, а также поиск квестов рядом через `GET /api/quests/nearby` с координатами устройства. Если у пользователя есть квест в статусе `in_progress`, над списком квестов и фильтрами ДОЛЖЕН отображаться блок активного квеста.

#### Scenario: S06 — Список квестов с фильтрами
- **WHEN** пользователь открывает каталог
- **THEN** приложение загружает список квестов с пагинацией
- **AND** фильтры по городу/сложности/популярности корректно применяются

#### Scenario: Отображение активного квеста над каталогом
- **WHEN** пользователь открывает каталог и имеет активный прогресс квеста
- **THEN** над фильтрами и списком квестов отображается блок «Активный квест»
- **AND** при клике на него открывается экран прохождения этого квеста
- **TESTS**:
  - Integration: `mobile/lib/app/features/quests/presentation/screens/home_screen.dart` проверяет провайдер `progressListControllerProvider` и корректно встраивает `ActiveQuestBlock`.

#### Scenario: S07 — Города с кешем
- **WHEN** приложение запрашивает справочник городов
- **THEN** данные кешируются локально с TTL 1 час (как в веб-клиенте)
- **AND** при отсутствии сети используется кешированная версия

#### Scenario: S08 — Квесты рядом
- **WHEN** пользователь запрашивает квесты поблизости
- **THEN** приложение запрашивает георазрешения и отправляет координаты на `GET /api/quests/nearby`
- **AND** результаты отсортированы по удаленности
- **AND** при отказе в георазрешении приложение корректно объясняет, как включить геолокацию
