## Why

В настоящее время на главном экране приложения отображается только список квестов и фильтры. Если пользователь уже начал квест (есть активный прогресс), ему неудобно возвращаться к нему, так как нужно искать квест в общем списке или переходить в профиль. Отображение блока с активным квестом на главном экране (только в мобильном приложении) позволит пользователям быстро и удобно продолжать игру. Вынесение этого компонента в дизайн-систему позволит переиспользовать его на других экранах (например, в профиле или геолокации).

## What Changes

- Добавление блока «Активный квест» на главный экран мобильного приложения (выше списка квестов и фильтров).
- Блок отображается только в том случае, если у пользователя есть хотя бы один квест в статусе `in_progress`.
- Вынесение UI-компонента блока активного квеста в изолированный переиспользуемый компонент внутри дизайн-системы Flutter-приложения.
- Интеграция компонента с текущим состоянием пользователя (использование Riverpod provider для получения статуса прогресса).
- **ВАЖНО:** Изменения применяются только для мобильного приложения (Flutter). Web-версия не затрагивается.

## Capabilities

### New Capabilities
- `design-system/active-quest-block-mobile`: Спецификация переиспользуемого UI-компонента для отображения активного квеста во Flutter-приложении.

### Modified Capabilities
- `mobile-app`: Изменение структуры каталога (главного экрана) — добавление блока активного квеста над списком квестов.

## Impact

- **Mobile (Flutter):** Изменение главного экрана приложения (`main_screen` или аналогичный), добавление нового компонента в дизайн-систему (`lib/app/core/design_system` или аналогичная директория). Интеграция с существующим Riverpod-провайдером для `UserProgress`.
- **Frontend (Web):** Влияния нет.
- **Backend:** Влияния нет, API для получения прогресса пользователя уже существует.
