# Архитектура домена Geolocation

Домен `geolocation` отвечает за работу с геоданными: список доступных городов, вычисление расстояний и проверку геолокации.

## 1. Справочник городов

**Presentation:** REST-контроллер `CityController`, реализующий эндпоинт `/api/cities`.

Справочник городов не использует базу данных. Данные загружаются из статической конфигурации Symfony (`app.cities`), что обеспечивает максимальную производительность.
- Данные преобразуются в массив объектов вида `[{ "key": "moscow", "name": "Москва" }]`.
- Результат сортируется по алфавиту (по русскому названию) прямо в контроллере с помощью `usort`.
- Доступ к справочнику публичный, не требует JWT авторизации.

## 2. Геолокационные расчеты
Для вычисления расстояния между двумя координатами (широта и долгота) `GeolocationService` использует **формулу гаверсинуса** (Haversine formula).
- Предполагаемый радиус Земли жестко задан как константа: `EARTH_RADIUS_METERS = 6371000` (в метрах).
- Все дистанции и радиусы измеряются и сравниваются в метрах.
- Проверка вхождения в радиус (`isWithinRadius`) является инклюзивной (расстояние `<= radius`).
