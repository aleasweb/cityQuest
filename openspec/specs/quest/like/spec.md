# Quest Like Specification

## Purpose
Определяет механизмы добавления и удаления лайков квестам, а также учет их количества.

## Requirements

### Requirement: Toggle Like
Система ДОЛЖНА позволять авторизованным пользователям ставить и убирать лайки квестам.

#### Scenario: Liking a quest
- **WHEN** авторизованный клиент отправляет POST запрос на `/api/quests/{id}/like` для квеста, который он еще не лайкнул
- **THEN** система создает запись о лайке
- **AND** увеличивает счетчик `likesCount` у квеста на 1
- **AND** возвращает успешный ответ с обновленным статусом

#### Scenario: Unliking a quest
- **WHEN** авторизованный клиент отправляет POST запрос на `/api/quests/{id}/like` для квеста, который он уже лайкнул
- **THEN** система удаляет запись о лайке
- **AND** уменьшает счетчик `likesCount` у квеста на 1
- **AND** возвращает успешный ответ с обновленным статусом

### Requirement: Authentication for Likes
Система ДОЛЖНА запрещать неавторизованным пользователям изменять статус лайка.

#### Scenario: Unauthorized like attempt
- **WHEN** неаутентифицированный клиент пытается отправить запрос на `/api/quests/{id}/like`
- **THEN** система возвращает ошибку 401 Unauthorized

### Requirement: Single Like Per User
Система ДОЛЖНА гарантировать, что один пользователь может поставить только один лайк одному квесту.

#### Scenario: Duplicate like prevention
- **WHEN** система обрабатывает запрос на лайк
- **THEN** она опирается на уникальное ограничение (user, quest), чтобы предотвратить дублирование
