# Quest Step Specification

## Purpose
Определяет структуру и механизмы работы с этапами (чекпоинтами) квестов в проекте CityQuest.

## Requirements

### Requirement: Quest Steps Listing
Система ДОЛЖНА предоставлять список этапов для заданного квеста.

#### Scenario: Fetching steps for a quest
- **WHEN** клиент запрашивает список этапов для существующего квеста
- **THEN** система возвращает массив этапов, отсортированных по полю `number` по возрастанию

### Requirement: Step Data Integrity
Каждый этап ДОЛЖЕН содержать необходимые данные для навигации и контент этапа.

#### Scenario: Step structure validation
- **WHEN** система возвращает данные этапа
- **THEN** данные включают координаты (`lat`, `lng`), радиус срабатывания (`radius`), порядковый номер (`number`) и опциональный медиа-контент (`title`, `text`, `imageUrl`, `audioUrl`, `videoUrl`)

### Requirement: Step Status
Система ДОЛЖНА поддерживать статус этапа (активен/неактивен), чтобы позволять авторам временно отключать определенные чекпоинты без их удаления.

#### Scenario: Filtering active steps
- **WHEN** клиент запрашивает этапы квеста
- **THEN** система возвращает только те этапы, у которых `status` указывает на их активность (например, `status = 1`)
