# active-quest-block-mobile Specification

## Purpose
Предоставляет переиспользуемый UI-компонент для отображения краткой информации об активном квесте пользователя в мобильном приложении.

## Requirements

### Requirement: Отображение карточки активного квеста
Компонент ДОЛЖЕН отображать название квеста, текущий прогресс (номер текущего шага и общее количество шагов) и кнопку или индикатор для перехода к экрану прохождения.

#### Scenario: Успешное отображение компонента
- **GIVEN** пользователь имеет активный квест
- **WHEN** компонент получает данные о прогрессе квеста со статусом в процессе
- **THEN** он корректно рендерит название квеста, прогресс и кнопку продолжения
- **AND** при нажатии на компонент или кнопку происходит навигация на экран прохождения этого квеста

#### Scenario: Отсутствие активного квеста
- **GIVEN** пользователь не имеет активного квеста
- **WHEN** компонент не получает данных о прогрессе или статус не указывает на активный процесс
- **THEN** компонент ничего не рендерит и не занимает место на экране
